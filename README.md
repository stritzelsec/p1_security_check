# P1 – Security Login Check

## About the Project

This is my first Python project, created as part of my journey into cybersecurity and programming.

The program simulates a simple PIN-based login system. The user has a limited number of attempts to enter the correct PIN. If all attempts fail, access is denied.

## Features

- PIN verification
- Configurable maximum number of attempts
- Counter for failed attempts
- Display of remaining attempts
- Access granted when the correct PIN is entered
- Lockout message after the maximum number of failed attempts

## Technologies

- Python 3
- Visual Studio Code
- Ubuntu Linux

## How to Run

Run the script from a terminal using:

```bash
python3 security_check_login.py
```

## Security Note

This project is an educational simulation. The PIN is stored directly in the source code, and the program does not implement secure authentication. It is not intended for use as a real login or security system.
